# Step 1: Data Collection

## Project Title
Library Management Book Availability System

## Objective
To analyze library book borrowing, returns, reservations, and availability using a dataset.

## Data Source
The project uses the library dataset stored in `data/raw/library_datasets.csv`.

## Dataset Preparation
The original dataset was collected and stored separately from the cleaned dataset.

- Original dataset: `data/raw/library_datasets.csv`
- Cleaned dataset: `data/processed/library_datasets_cleaned.csv`

## Tools Used
- Python
- Pandas
- Visual Studio Code
- Git and GitHub

## Outcome
The dataset is available for inspection, cleaning, analysis, visualization, and interactive dashboard development.
This step collects library book data, checks for missing values and duplicates, and saves the cleaned dataset for further analysis.git
